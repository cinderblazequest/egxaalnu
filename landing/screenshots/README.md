# Скриншоты бота для лендинга

Сюда положите 3–6 скриншотов экрана Telegram-бота на телефоне:

* `home.png` — главное меню с кнопками
* `scenario.png` — открытый сценарий с шагами
* `metronome.png` — отправка метронома
* `aed.png` — карта АНД с ближайшим
* `panic.png` — panic-режим
* `dashboard.png` — Streamlit-дашборд

Размер: ширина 750–1080 px, формат PNG, без личных данных пользователей.
Хранить в репо: только `README.md` и не более 6 PNG до 200 КБ каждый.
Большие версии — на S3/Yandex Object Storage.
