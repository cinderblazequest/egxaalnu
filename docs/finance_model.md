## Источники финансирования

1. **Гранты для НКО / молодёжных проектов**:
   - Президентский фонд культурных инициатив (до 3 млн ₽).
   - Росмолодёжь.Гранты (до 1.5 млн ₽).
   - Фонд президентских грантов (до 5 млн ₽).
2. **Региональные программы**:
   - Грант мэра Москвы для молодёжных проектов.
   - Министерства образования регионов.
3. **Партнёрства** (in-kind):
   - GigaChat — расширенная квота API (без денег).
   - Telegram Stars / GitHub Education — bonus credit.
4. **Краудфандинг (резерв)**:
   - Boomstarter, ВК Donate.
