## Минимально‑необходимое чтобы выйти в продакшн (1 вечер)

1. Получить **BOT_TOKEN** через [@BotFather](https://t.me/BotFather).
2. Зарегистрироваться на **[Fly.io](https://fly.io)** (free tier).
3. Развернуть бот по инструкции в `README.md` (~30 минут).
4. Открыть бот в Telegram, проверить `/start` и пройти один сценарий.

## Минимально‑необходимое чтобы попасть в финал (10 вечеров)

1. См. `docs/spas_ai_concept_and_27day_plan.md`, раздел «27‑дневный план».
2. Запустить бот в продакшен (4–5 мая).
3. Собрать ≥200 пользователей (19–25 мая).
4. Получить 4 письма поддержки (22–24 мая).
5. Опубликовать колонку на VC.ru / Дзене (23 мая).
6. Заполнить заявку (`docs/spas_ai_application_text.md`) и подать (31 мая).
