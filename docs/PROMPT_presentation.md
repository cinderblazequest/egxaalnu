# Промпт для генерации презентации проекта СПАС

Используется для генерации **полной презентации жюри** в любом
AI-инструменте: ChatGPT, Claude, Gemini, Gamma, Beautiful.ai, Tome.

Скопируй промпт ниже целиком и вставь в выбранный AI. Замени все
плейсхолдеры в `<…>` на свои данные перед отправкой.

---

## ПРОМПТ (вставлять целиком)

```

СТРУКТУРА СЛАЙДОВ (придерживайся строго):

Слайд 5 — Контент и доказательная база.
```

## Как использовать

1. Скопируй промпт выше.
2. Замени `<BOT_USERNAME>` на `@SPAS_HEALTH_BOT`,
   `<BOT_USERNAME_WITHOUT_AT>` на `SPAS_HEALTH_BOT`,
   `<USER>`/`<REPO>` на свои GitHub-координаты.
3. Замени `<AUTHOR_NAME>`, `<SCHOOL>`, `<CITY>`, `<MENTOR>`.
4. Сгенерируй QR-код на `https://t.me/SPAS_HEALTH_BOT` и сохрани
   в `docs/qr_spas_health_bot.png`.
5. Скорми промпт ChatGPT/Gemini/Claude. Полученный Marp-Markdown
   сохрани как `docs/jury_deck.md` (перезапиши существующий
   скелет) и собери в PDF командой
   `npx --yes @marp-team/marp-cli docs/jury_deck.md --pdf
    --allow-local-files --output docs/jury_deck.pdf`.

## Альтернативные инструменты

- **Gamma**: вставь промпт целиком в «Generate from text» — Gamma
  сама подберёт макеты и иконки. Скачай PDF/PPTX.
- **Tome**: аналогично, в «Generate from prompt».
- **Beautiful.ai**: в «AI Designer» → «Generate slides».
- **Marp (локально)**: получи Markdown и собирай в PDF через
  `marp-cli`. Это даёт максимальный контроль над вёрсткой.

## Что нельзя забыть подменить

- `<BOT_USERNAME>` → `@SPAS_HEALTH_BOT`
- `<QR_BOT_URL>` → реальный QR на бота
- `<SCREENSHOT_*>` → скриншоты из бота
  (см. `landing/screenshots/README.md` — туда сохраняем PNG'ки)
- `<AUTHOR_NAME>`, `<SCHOOL>`, `<CITY>`, `<MENTOR>` → данные автора
