# FAQ — СПАС

Часто задаваемые вопросы. Если у тебя нет ответа здесь — открой issue
на GitHub или напиши в Telegram-канал.

## Для пользователей

### Это бесплатно?
Да. Проект полностью бесплатный для всех. Код открыт под Apache 2.0,
учебный контент — под CC BY-NC-SA 4.0.

### Я в опасной ситуации, что делать?
1. Открой Telegram и набери `/sos` боту @your_bot_username — выбери
   сценарий и иди по шагам.
2. **Сначала позвони 112** (или 103). Бот не заменяет скорую.
3. Если страшно — нажми `/panic` или красную кнопку «мне страшно».
4. Если не получается дозвониться — звонок 112 без баланса работает
   с любой SIM-карты.

### Бот ставит диагнозы?
Нет. СПАС не ставит диагнозы. Он показывает базовые шаги по приказу
Минздрава №477н и протоколам Российского национального совета по
реанимации. Любая медицинская проблема — на 112.

### Откуда у меня возьмётся опыт?
СПАС — это **тренажёр**: 30 сценариев, pre/post тесты и сертификат
после 3 пройденных. Используй сценарии в спокойное время — чтобы в
острой ситуации руки уже знали, что делать.

### А если интернет пропал?
В MVP бот работает только при наличии интернета. В Q3 2026 будет
PWA-версия с офлайн-сценариями. Уже сейчас можно скачать
`content/scenarios.json` из репо и держать на телефоне как резерв.

### Бот собирает мои данные?
Минимум: Telegram ID, регион (по желанию), факты прохождения сценариев,
ответы на тесты, согласие на обработку. **Имена, телефоны, точная
геолокация — не собираются.**

### Я хочу добавить точку АНД (дефибриллятора)
В боте нажми кнопку «Карта АНД» → «Добавить точку», поделись геолокацией
и опиши место. Точка появится после модерации.

## Для родителей и учителей

### Можно ли использовать СПАС в школе?
Да. См. `docs/methodology_brief.md` — там 45-минутный план урока ОБЖ
(9–11 класс), 15-минутное активити для библиотек/центров и
5-дневная неделя «Я знаю, как помочь».

### Это безопасно для подростка?
Да. Все алгоритмы прошли проверку врача-ментора. В каждом сценарии
напоминание «Сначала позвони 112». В panic-режиме — телефон доверия
8-800-2000-122. Бот не предлагает медикаменты и не ставит диагнозы.

### Я учитель, нужен ли мне аккаунт для класса?
Нет. Каждый ученик заходит в бот сам со своего Telegram. В классе
учитель показывает экран с 1 устройства и каждый параллельно проходит
свой сценарий. Метрики класса собираются по UTM-метке (см. методичку).

### Как мне попасть в пилот?
Напиши автору на email или в Telegram. Подпишите письмо поддержки
по шаблону `docs/support_letter_template.md`.

## Для медиков

### Откуда взяты алгоритмы?
- Приказ Минздрава России №477н (2012, ред. 2020).
- Рекомендации Российского национального совета по реанимации (2024).
- Гайдлайны European Resuscitation Council (ERC 2021) — в части,
  совместимой с российскими протоколами.

### Как сообщить об ошибке?
Открой issue на GitHub или напиши в Telegram-канал.
Каждое сообщение об ошибке проверяется ментором-врачом.

### Можно использовать в обучении студентов-медиков?
Да, но только как иллюстрацию для обывателя. Профессиональные
протоколы — другие. Контент под CC BY-NC-SA 4.0 — некоммерческое
использование с указанием авторства разрешено.

## Для разработчиков

### На чём написан бот?
Python 3.11, aiogram 3.x, SQLite, ReportLab (сертификаты).
Деплой на Fly.io free tier с persistent volume.

### Как развернуть свою копию?
1. `git clone https://github.com/your-username/spas-ai`
2. `cp .env.example .env` → впиши BOT_TOKEN
3. `pip install -r requirements.txt`
4. `python -m bot`

### Можно ли сделать форк?
Да, лицензия Apache 2.0 разрешает форк. Прошу:
- Сохранить дисклеймер «Сначала 112».
- Не убирать упоминание медицинских источников.
- Прислать pull request с улучшениями обратно — наша цель,
  чтобы алгоритмы становились лучше у всех.

### Как добавить сценарий?
1. Дополни `content/scenarios.json` — есть схема в `tools/validate_content.py`.
2. Запусти `python tools/validate_content.py` — должно пройти без ошибок.
3. PR в основную ветку.

### Где база АНД?
`content/aed_locations.json`. Краудсорсные точки попадают через
`bot/aed_submission.py` после модерации (см. `bot/handlers.py` → `/admin_aed`).
