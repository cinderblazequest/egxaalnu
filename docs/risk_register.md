# Реестр рисков СПАС

Последнее обновление: 7 мая 2026.

| # | Риск | Вероятность | Влияние | Митигация |
| --- | --- | --- | --- | --- |
| R1 | Бот выдаст ошибочный совет, человек пострадает | Низкая | Критическое | Все алгоритмы — приказ Минздрава №477н + проверка врача-ментора. В каждом сценарии напоминание «Сначала позвони 112». Юр. дисклеймер на лендинге. |
| R2 | Telegram заблокирует бот / снизит охват | Средняя | Высокое | Запасной канал: VK-сообщество + PWA-версия (Q3). Open-source — любой регион может развернуть форк. |
| R3 | LLM (GigaChat) вернёт некорректный ответ на вопрос | Средняя | Среднее | Свободная Q&A только информативно, с дисклеймером, не входит в сценарии. Все критичные шаги — статичные. |
| R4 | Не успеваем к 31 мая | Средняя | Среднее | MVP уже работает; новые фичи — best effort, не блокеры подачи. |
| R5 | Не удастся собрать 4 письма поддержки | Средняя | Высокое | Шаблон писем + SMM-рассылка по 30+ школам и СОНКО уже на этой неделе. |
| R6 | Технический сбой Fly.io / SQLite | Низкая | Высокое | Persistent volume + еженедельный бекап SQLite на S3-совместимое хранилище. Подготовлен план ручного перезапуска. |
| R7 | Утечка персональных данных пользователей | Низкая | Критическое | Храним только Telegram ID и обезличенные метрики. Не собираем имена, телефоны, геолокации (кроме одной точки для AED). PD-политика на лендинге. |
| R8 | Бот неправильно поймёт геолокацию (краудсорс AED) | Высокая | Среднее | Все добавленные точки модерируются вручную через `/admin_aed` (статус pending → approved/rejected). |
| R9 | Подросток в panic-режиме реально в кризисе (СОЖ-риск) | Низкая | Критическое | В /panic — обязательная плашка телефона доверия 8-800-2000-122. Не ставим диагнозов. |
| R10 | Использование бота нечестно для конкурса | Низкая | Среднее | Open-source с публичной историей коммитов и CHANGELOG. Все метрики — из публичного дашборда. |
| R11 | Региональная сторона требует адаптации (нет 112) | Низкая | Низкое | Конфиг номера экстренного вызова в env (DEFAULT 112). |
| R12 | Технические долги тормозят масштабирование | Средняя | Среднее | Тесты + lint + CI с 1-го дня. Метрика покрытия. Документ `CONTRIBUTING.md` для внешних контрибьюторов. |

## Эскалация

- R1, R7, R9 — мгновенная остановка фичи + связь с ментором-врачом и юристом.
- R2, R6 — резервный план в течение 24 ч.
- R4 — еженедельный апдейт по дорожной карте на встрече с ментором.
