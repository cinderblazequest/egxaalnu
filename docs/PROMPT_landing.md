# Промпт для генерации лендинга проекта СПАС

Используется для генерации **одностраничного лендинга** в любом
no-code/AI-инструменте: v0.dev, Lovable, Bolt.new, Cursor,
Framer AI, Webflow AI, Tilda AI. Также подходит для генерации
чистого HTML/Tailwind в ChatGPT/Claude.

---

## ПРОМПТ (вставлять целиком)

```
Сгенерируй одностраничный лендинг (Landing page) для проекта
«СПАС» — бесплатный AI-помощник первой помощи для подростков
14–17 лет в Telegram. Лендинг должен быть production-ready:
адаптивный (мобильные/планшеты/десктоп), быстрый, доступный по
WCAG AA, в темной и светлой темах (auto по prefers-color-scheme).

ТЕХНОЛОГИИ:
- Чистый HTML5 + Tailwind CSS (через CDN), либо React + Next.js
  (для v0.dev / Lovable).
- Без сторонних трекеров и cookies (152-ФЗ).
- PWA: manifest.webmanifest + service-worker.js с офлайн-fallback
  на главную страницу (минимально — кэш статических ассетов).
- Поддержка screen reader'ов: правильные landmark'и
  (header/nav/main/footer), ARIA-атрибуты на интерактивных
  элементах, контрастные цвета.

БРЕНДИНГ:
- Основной цвет: red-500 (#FF3B30), как у настоящих служб
  спасения и Apple Emergency SOS.
- Фон: white (#FFFFFF) для light-режима, #0B0D10 для dark.
- Шрифт: Inter или системный sans-serif.
- Лого: ⛑ (эмодзи каска спасателя) или текст «СПАС» в
  red-500 жирный.
- Никаких стоковых картинок «улыбающихся врачей». Только
  иконки (Lucide / Phosphor) и реальные скриншоты бота.

СТРУКТУРА СТРАНИЦЫ (сверху вниз):

1) HERO (полный экран, 100vh).
   - Заголовок H1: «СПАС — первая помощь у тебя в Telegram».
   - Подзаголовок: «30 сценариев. Тесты до и после. Сертификат.
     Бесплатно. Без рекламы.»
   - Две кнопки рядом:
       - Primary, красная, большая: «Открыть в Telegram»,
         ведёт на `https://t.me/SPAS_HEALTH_BOT`.
       - Secondary, outline: «Узнать больше» — якорь к секции
         How-it-works.
   - Справа от текста — скриншот главного меню бота
     (mockup в frame iPhone-mini).
   - Внизу: маленький disclaimer-баннер «Это справочный
     сервис. При угрозе жизни — 112».

2) SOCIAL PROOF / SHORT STATS (горизонтальный ряд из 4 карточек).
   - «30» сценариев первой помощи
   - «4» языка (RU / EN / UZ / KK)
   - «1»-минутный старт без регистрации
   - «100%» открытый исходный код (Apache 2.0)

3) HOW IT WORKS (3-4 шага горизонтально).
   - 1. Открыть бота → 2. Выбрать сценарий → 3. Пройти шаги →
     4. Получить сертификат.
   - Каждый шаг с иконкой и подписью (1-2 строки).

4) FEATURES (сетка 2 × 3 карточек, по одной фиче на карточку).
   - 🚑 30 пошаговых сценариев — СЛР, удушье, кровотечения,
     ожоги, переломы, инсульт, припадок и др.
   - 🧠 Pre- и post-тесты — закрепить знания до и после
     сценария.
   - 📞 Чек-лист для 112 — соберёт сообщение для диспетчера за
     30 секунд.
   - 😌 Панический протокол — успокоиться через дыхание 4-7-8
     и grounding 5-4-3-2-1.
   - 🥁 Метроном для СЛР — звук 100 BPM, чтобы попадать в темп
     компрессий.
   - 🎓 Геймификация — XP, уровни, ачивки, лидерборд,
     сертификат с QR-кодом.

5) FOR EDUCATORS (отдельная секция для учителей и школ).
   - «Учителям ОБЖ и медицинским кружкам: используйте СПАС как
     дополнительный материал».
   - 3 буллета: «Сертификаты для учеников», «Аналитика
     прохождения», «Открытый код — можно развернуть у себя».

6) FOR ORGANIZATIONS (отдельный блок про Max-версию).

7) ETHICS & PRIVACY (важно для жюри).
   - Заголовок: «Что важно знать».

     - «Не заменяет врачей. Это обучение и поддержка в первые

8) FAQ (5-7 вопросов в аккордеоне).
   - «Это безопасно для подростка?» — «Да. Бот не собирает

   - «Как помочь проекту?» — «Звезда на GitHub, пилот в вашей

9) FOOTER.
   - Слева: «© 2026 СПАС. Apache 2.0».
   - В центре: ссылки «GitHub», «Telegram бот», «Лицензия

ИНТЕГРАЦИИ:

- GitHub-ссылка: `https://github.com/<USER>/<REPO>`.

SEO META:

- og:image: скриншот бота 1200×630.

PWA:

ОГРАНИЧЕНИЯ:

ФАЙЛОВАЯ СТРУКТУРА (вывод):

ВЫХОД: верни полный HTML-код страницы. Если используешь
```

## Как использовать

1. Скопируй промпт выше.
2. Замени:
   - `https://t.me/SPAS_HEALTH_BOT` оставь как есть, либо
     поменяй на актуальный username.
   - `<USER>/<REPO>` — на свои GitHub-координаты.
   - `<CONTACT_EMAIL>` — на email для связи (можно создать
     отдельный `spas.bot@yandex.ru`).
   - `<DOMAIN>` — если есть свой домен (например `spas-bot.ru`).
3. Скорми промпт инструменту:
   - **v0.dev** (рекомендую) — даёт готовый React-компонент
     для Next.js.
   - **Lovable** или **Bolt.new** — генерирует полный проект.
   - **ChatGPT/Claude** — попроси «Верни полный одиночный
     HTML-файл», получишь self-contained index.html.
4. Сохрани результат в `landing/index.html` (перезапиши
   существующий) и закоммить. Локально открой
   `python -m http.server -d landing 8000` для проверки.
5. Сделай 4 локали — перевод с тем же макетом — для `index.en.html`,
   `index.uz.html`, `index.kk.html` (попроси AI «переведи
   на английский/узбекский/казахский»).

## Совет по картинкам

- Скриншоты бота сделай в Telegram Web (light + dark), обрежь до
  ~360×780 для мобильного mockup.
- Не используй сток. Лучше нарисуй SVG-иконки сам или возьми
  Lucide Icons (MIT).
- Для hero — сделай простой mockup iPhone-mini в Figma с
  залитым скриншотом.

## Если нужен только бот-CTA (минимальный лендинг)

Если хочешь самый простой вариант:

```
Одностраничный лендинг для Telegram-бота @SPAS_HEALTH_BOT —
карманного AI-помощника первой помощи для подростков.

Структура: hero с большой красной кнопкой «Открыть в Telegram»
ведёт на https://t.me/SPAS_HEALTH_BOT, под ней список из 4
ключевых фишек (30 сценариев, тесты, сертификат, бесплатно).
В футере — ссылка на GitHub и дисклеймер «при опасности 112».

Технологии: один HTML-файл, Tailwind через CDN, mobile-first,
светлая тема. PWA не нужна. Верни готовый index.html.
```

Этот короткий промпт скорми в ChatGPT — получишь чистый
одностраничный HTML за один запрос.
