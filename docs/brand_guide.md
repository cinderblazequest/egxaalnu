# СПАС — Brand Guide

> Подростковый AI-помощник первой помощи. Конкурс «Моя страна — Моя Россия» 2026, категория «Моё здоровье», возраст 14-17.

## 1. Голос и тон

| Контекст              | Тон | Пример |
|-----------------------|-----|--------|
| Обычное взаимодействие | Дружелюбный, на «ты», без сленга | «Подышим вместе?» |
| Экстренная ситуация    | Короткие команды, императив, **жирный** | «**ЗВОНИ 112. СЕЙЧАС.**» |
| Тесты и сценарии       | Тёплый менторский | «Хорошо! Давай разберём шаг за шагом» |
| Юридические тексты     | Нейтральный, ясный, без бюрократии | «Мы храним только user_id, язык и события» |
| Ошибки/сбои            | Извинение + альтернатива | «Не получилось. Попробуй текстом или /sos» |

**Никогда:**
- Не «лечим» — это справочный инструмент.
- Не угрожаем («Ты можешь умереть»).
- Не пишем «возможно», «вероятно» — в первой помощи это убивает время.
- Не «модно говорим» (slang, English mix) — подростки распознают фальшь.

## 2. Цвета

| Роль | HEX | RGB | Где |
|------|-----|-----|-----|
| **Тревога** (CTA, SOS) | `#E63946` | 230 57 70 | Кнопки экстренных действий, иконка |
| **Тёмная тревога** (gradient) | `#9B0E1A` | 155 14 26 | Фон лого, hover SOS |

Контрастность: все CTA вычислены так, что соотношение фона/текста ≥ 4.5:1 (WCAG AA).

## 3. Типографика

- Основной шрифт: **Inter** (Google Fonts, OFL).
- Запасной: `system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif`.
- В сценариях шаги — `font-weight: 600`, размер 18px (mobile 16px).
- Дисклеймеры — `font-style: italic`, `color: #6C757D`, размер 13px.

В Telegram используем HTML-форматирование: `<b>`, `<i>`, `<code>`. Эмодзи — только в статусах (✅ 🆘 🚨 ⚠️ 📞 🩹 🎓 ♿ 🔔 🛡️ 🗑️). В режиме `/accessibility` — без эмодзи и без HTML.

## 4. Логотип

- `landing/logo.svg` — 256×256, gradient red + белый плюс. Минимальный размер: 32×32 (иконка), 16×16 (favicon).
- Не растягивать, не менять цвет креста, не наклонять.
- Для тёмного фона — стандартный логотип ОК (есть тень).
- Для одноцветной печати: логотип без gradient (плоский `#E63946`, белый плюс, чёрный текст).

PWA-иконки: `landing/icons/icon-192.png` и `icon-512.png` генерируются скриптом `tools/generate_icons.py`.

## 5. Иконография

- Для категорий: 🚨 critical, ⚠️ urgent, 🩹 minor, 🎓 certificate, 🏆 leaderboard, 🆘 SOS.
- В сценариях каждый имеет `icon` поле (emoji) — это его «бренд».

## 7. Запрещено

- Кровавые иконки, реалистичные раны.
- Юридический жаргон в UI («оператор персональных данных…», «субъект персональных данных» — заменяем на «пользователь», «ты»).
- Реклама и сторонние ссылки в флоу первой помощи.
- Использование лого ВКонтакте, МЧС, Минздрава без разрешения (мы НЕ официальный сервис этих организаций).
