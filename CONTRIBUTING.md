# Contributing to СПАС

Спасибо, что хотите помочь сделать «СПАС» лучше. Здесь правила и идеи, как
встроиться эффективно.

## Как помочь

1. **Контент сценариев** — предложите новый сценарий или улучшите
   существующий через issue или pull request. Изменения проходят
   медицинскую вычитку у консультанта проекта (см. `docs/METHODOLOGY.md`).
2. **АНД-точки** — если вы знаете публично доступный дефибриллятор,
   добавьте его в `content/aed_locations.json` или используйте команду
   `/add_aed` в самом боте.
3. **Код и тесты** — UI-улучшения, новые тесты, рефакторинг.
4. **Перевод** — пока RU/EN. Если хотите добавить язык — открывайте
   issue.

## Технический процесс

1. Форкните репозиторий.
2. Создайте ветку `git checkout -b feature/short-description`.
3. Установите dev-окружение: `make dev`.
4. Перед коммитом — `make lint && make test`.
5. Откройте Pull Request в `main` с описанием.

## Стиль кода

* Python 3.11+, типизация обязательна (`from __future__ import annotations`).
* Длина строки — 110 символов.
* Линтер — ruff, конфиг в `pyproject.toml`.
* Тесты — pytest, помещайте рядом с тестируемым модулем
  (`tests/test_*.py`).

## Контент-политика

Этот проект — **справочно-информационный**. Мы не пишем шаги, которые
противоречат:

* открытым рекомендациям [Российского Национального Совета по
  реанимации](https://www.rusnrc.com/);
* [ERC Guidelines](https://www.erc.edu/) (текущая версия);
* позиции Минздрава РФ.

Если вы добавляете медицинский контент — приложите ссылку на источник
в описании коммита и/или PR. Спорные шаги обсуждаются с медконсультантом.

## Безопасность

Если нашли уязвимость — пишите по адресу из `SECURITY.md`. Не
открывайте публичный issue.
